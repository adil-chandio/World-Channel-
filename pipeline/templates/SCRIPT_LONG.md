# Long-Form Script — Template

> Format: **Caught on Camera — Explained.** Storytelling + forensic explainer over real clips.
> Runtime target: **7–9 min** (Too Close) or **6–8 min** (Hidden Tricks). Read time ≈ 145 wpm.

## Video
- **ID:** BRIEF-XX
- **Working title:**
- **One promise** (what the viewer gets in one sentence):
- **Series:** Too Close: Wildlife in Human Space / Nature's Hidden Tricks

## VOICE & TONE RULES (non-negotiable)

- Natural, mature, clear native-English. Sounds like a real wildlife creator, not a translated
  script, announcer, or forced viral personality.
- Calibrated language: "attack", "charged", "aggressive" only when the footage supports it.
- Banned phrases: "pure wild attitude", "silent death", "no mercy", "absolute nightmare",
  "will terrify you", "you won't believe", "but it gets crazier".
- Every factual claim about behaviour/species carries a source marker [[n]] → sources at the end.
- One new visual or insight every 20–40 seconds. No filler transitions.

## STRUCTURE

| Time | Block | Content |
|---|---|---|
| 0:00–0:03 | **HOOK — proof first** | Strongest visual from the thumbnail. No logo. No "Imagine...". |
| 0:03–0:12 | **Question / story promise** | One sentence: what this video resolves. |
| 0:12–0:30 | **Small payoff + first insight** | Don't only promise a later payoff — give one now. |
| 0:30–6:30 | **Story body** | 3–5 compact real examples, each answering a different "why". Beat map below. |
| 6:30–8:00 | **Context / explainer** | The forensic insight: what the camera doesn't show, the science, the pattern. |
| 8:00–8:40 | **Final beat + take-away** | Last surprise or practical context (safety, behaviour). |
| last 20s | **End screen** | Spoken handoff: "If this [x] surprised you, watch what happened at [next]." + video + playlist. |
