# Pre-Publish Checklist (every upload)

## Rights & policy
- [ ] Every clip in the video is `cleared` in `ops/rights-ledger.csv`
- [ ] Credits included in description where required
- [ ] Claims in the script are sourced; no unverified behaviour/species claims
- [ ] Distress/harm content framed non-graphically; advertiser-unfriendly flags checked
- [ ] Altered/synthetic content labelled if (and only if) required by YouTube policy

## Content quality
- [ ] 0:00–0:03 pays off the thumbnail (proof first — no logo intro)
- [ ] One promise, delivered; no overclaiming ("attack", "terrify", etc.)
- [ ] New visual/insight every 20–40 s
- [ ] Natural English narration; no banned phrases
- [ ] TV-safe: legible text, clean 16:9, narration above music

## Packaging
- [ ] Title standalone (no "Part 2/3/4"), one promise, title case
- [ ] Thumbnail: one subject, one emotion, 0–3 words, readable at 98×98
- [ ] Description: line-1 payoff, context, credits, playlist + next video links
- [ ] Chapters with timestamps
- [ ] Pinned comment written (ready to paste after publish)

## End screen & series
- [ ] Spoken handoff line in the last 20 s
- [ ] End-screen video element = highly relevant next video (not random)
- [ ] Playlist element (Too Close / Hidden Tricks)
- [ ] Subscribe element

## Shorts wiring
- [ ] Each Short: description line 1 → long video; pinned comment → long video
- [ ] End cue "Full story on Monarch Cam" burned in
- [ ] Publish times per `ops/content-calendar.md`

## After publish (owner)
- [ ] Pin the comment immediately
- [ ] Reply to early comments (first 2 hours matter)
- [ ] Log 1 h metrics in `ops/metrics-dashboard.md`
